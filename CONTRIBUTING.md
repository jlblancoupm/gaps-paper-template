# Contributing

Keep the common template generic.

Paper-specific scientific logic should not be added to the shared template unless it is reusable across publications.

## Rules

1. Do not mix experiment generation and paper-figure rendering.
2. Do not fabricate numerical values for interactive demos.
3. Mark interactive provenance: exact / precomputed / interpolated / conceptual.
4. Keep external navigation in a new tab.
5. Keep author URLs empty until verified.
6. Keep BibTeX LaTeX-safe and protect meaningful capitalization with braces.
